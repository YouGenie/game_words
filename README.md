# Игра в слова:

Самая простая игра в слова, но только противником выступает модель **Llama-3.3-8B-Instruct-128K**. Игрок пишет любое слово, а в ответ ИИ пишет своё слово на последнюю букву игрока. Игрок всегда может писать любые слова, в то время как ИИ всегда будет предлагать слово на последнюю букву игрока. Реализован только самый необходимый функционал, поэтому лишних проверок на введёные слова игрока сделаны не были.

## Основные возможности:
- **Локальный запуск:** Все вычисления происходят на вашем ПК.
- **GPU Ускорение:** Использование библиотеки `llama-cpp-python` для быстрой генерации слов через видеокарту (хотя на CPU ответы тоже приходят быстро)
- **Авто-загрузка:** Скрипт сам скачивает нужную модель при первом запуске.

## Технологический стек:
- **Frontend:** Streamlit
- **Backend:** Python, FastAPI
- **Database:** SQLite (хранение всех слов)
- **AI Core:** llama-cpp-python (GGUF)
- **Model:** Llama-3.3-8B-Instruct-128K-GGUF (квантование Q4_K_M) (слишком маленькие модели часто выдавали некорректные слова)

## Быстрый старт

### 1. Подготовка окружения и активация:
```bash
git clone https://github.com
cd game_words
python -m venv venv

# Для Windows:
venv\Scripts\activate
# Для Linux или macOS:
source venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
*Примечание: Для ускорения на GPU (NVIDIA) необходимо заранее установить CUDA Toolkit и убедиться, что ваша видеокарта его поддерживает.*  

### 3. Запуск
- запустить сервер: uvicorn main:app --reload
- запустить приложение app.py

## Docker:
Чтобы запустить приложение через docker-compose, выполните пункты ниже:
- установить Docker
- выполнить docker-compose up --build
- открыть http://localhost:8501
